# Customize this portfolio

## 1. Replace images
Every project currently has a placeholder SVG under `assets/`.
Replace it with your real image and update the corresponding `image` field in `index.html` if the filename changes.

Recommended:
- Flagship project: 1 hero image + 3–6 supporting images
- Core project: 1 hero + 2–4 supporting images
- Supporting project: 1 hero + 1–2 supporting images

## 2. Fill TODO README files
Start with:
- `projects/nexcube/README.md`
- `projects/merc-robot/README.md`
- `projects/robot-arm-controller/README.md`
- `projects/rubber-ducky/README.md`

Do not use guessed numbers. Add your real role, architecture, components, results and links.

## 3. Update GitHub links
The current project links use your profile URL as a safe placeholder.
Replace each `github` value in `index.html` with the actual repository URL when known.

## 4. Add project galleries later
The current version uses a case-study modal so the website is lightweight.
The next version can give AMR and NEXCUBE long scrolling case-study sections, while shorter projects remain compact.
