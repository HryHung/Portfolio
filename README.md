# HryHung — Mechatronics & Robotics Portfolio

A scroll-based engineering portfolio designed for GitHub Pages.

## Structure

- `index.html` — portfolio interface
- `style.css` — visual system
- `script.js` — project navigation, filters and dynamic case studies
- `projects/` — one README per project
- `assets/` — replace placeholder SVGs with your real images

## Deploy

1. Create a repository named `HryHung.github.io` (or use any repo with GitHub Pages).
2. Upload the contents of this folder.
3. Enable GitHub Pages from the repository's Settings → Pages.
4. Set the source to the `main` branch and `/root`.
