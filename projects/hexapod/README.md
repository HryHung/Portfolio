# Hexapod Robot Platform

## Overview

A modular six-legged robotics platform for mechanical design, gait generation, inverse kinematics and embedded control experiments.

## My Role

Mechanical design · Kinematics · Embedded control

## Technical Stack

- ESP32
- Kinematics
- MATLAB
- SolidWorks
- Embedded C

## Engineering Details

### Mechanical

Six legs with 3 DOF each, modular joint / leg interfaces and a central control architecture.

### Control

High-level gait planning feeds inverse kinematics, then servo control and hardware drivers.

### Hardware

MCU-based controller, custom / DIY PCB work, modular power distribution and alignment system.

### Future

IMU / force feedback, advanced gaits, terrain adaptation and optional ROS integration.
