# Hand Gesture App

> Portfolio case-study draft. Replace the TODO sections with your final project details.

## Overview

A computer-vision application using MediaPipe and Streamlit to detect hand gestures, count fingers and implement gesture-based unlocking.

## My Role

Computer vision · Python · Interactive application

## Technical Stack

- Python
- MediaPipe
- OpenCV
- Streamlit

## Engineering Details

### Vision

MediaPipe hand landmarks are used to recognize hand posture and count fingers.

### Application

Streamlit provides an interactive interface for camera control, gesture recording and gesture unlocking.

### Features

Finger counting, hand landmarks, raw feature values and a recorded gesture password.

### Run

Python 3.10 environment with MediaPipe, Streamlit, OpenCV and NumPy.
